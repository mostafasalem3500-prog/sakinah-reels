تصدير الريل

ربط Google Drive

يحتاج الربط إلى «معرّف عميل OAuth» مجاني من Google Cloud — مرة واحدة فقط:

  1. افتح Google Cloud Console ← Credentials وأنشئ مشروعاً.
  2. فعّل Google Drive API (وGoogle Picker API اختيارياً).
  3. في «OAuth consent screen» اختر External وأضف بريدك كمستخدم اختبار.
  4. Create Credentials ← OAuth client ID ← Web application، وأضف في Authorized JavaScript origins:
  5. انسخ Client ID والصقه هنا. (لاختيار ملفات من كل الدرايف أنشئ أيضاً API key وانسخ رقم المشروع Project number).
الصلاحية المطلوبة drive.file فقط: لا يستطيع الموقع رؤية أي ملف في درايفك إلا ما أنشأه هو أو ما تختاره بنفسك.
